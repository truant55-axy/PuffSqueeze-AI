# Tree-hole Poetry / 树洞小诗

## 页面与双语

- 保留浅蓝信纸、首页选中的动物递信、可保存的诗卡。
- 所有新回信均为中英双语：英文标题＋中文标题，英文诗句下方紧跟其对应中文。
- 全站语言切换只改变按钮、提示与说明，不重新生成诗，也不隐藏其中一种语言。
- 支持三行短诗、一封短笺（四行）、自由诗（五行）；不宣称符合严格俳句音节。

## 生成方式

`src/services/treeholePoetry.ts` 存放原创中英词库、主题关键词、意象及 Tracery 模板。

每个词库的 `en[i]` 与 `zh[i]` 必须表达同一句话。生成时 Tracery 只选择一次句对 ID，再从该 ID 取出两种语言。切勿分别随机生成两首诗，也不要在翻译时重新抽句。

来信仅用于匹配预设关键词；用户可手动指定主题与意象。原文不会进入 Tracery 语法，不调用后端 AI、云端翻译或外部生成接口。未命中时使用休息主题，并非对用户情绪作出判断。

手动改写提供独立的中英文输入，要求两种语言诗句行数一致（1–12 行，每行最多 200 字）。不会自动翻译用户改写的内容。

## 保存与下载

- 按用户编号保存在 `localStorage` 的 `puffsqueeze_poetry_cards_<userId>`，上限 80 张。
- 新卡保留英文 `title` / `lines`，中文保存在 `translation`，两者一起保存。
- 旧版未修改的单语回信，可从既有词库查回其对应译文；不会重新随机生成或覆盖原文。
- 无法从词库恢复译文的旧版自定义回信保持原文，并在页面标记为旧单语内容。
- 图片与文字下载均保留标题和逐句中英对照，图片高度随内容调整。
- 来信原文仅在用户勾选附上后进入保存或下载。
- 内容只在当前浏览器内保存，不同步到其他设备；没有应用层加密。存储无法读取时拒绝覆盖，可继续下载新诗卡。
