# Quiet Cove / 慢慢钓鱼

## 入口与玩法

游戏页新增「慢慢钓鱼」。沿用首页选中的动物、成长形象和心情，使用浅蓝色水湾与原生 Canvas 绘制的小鱼。

- 按住键盘 `←` 或 `→`、用鼠标按住任一握持按钮，或用双指按住左右按钮：鱼钩下降。
- 两侧均松开：鱼钩上升，经过鱼身时捕获一条鱼。
- 两侧同时握住时取较大的压力值，释放一侧不会立即收钩。
- 每竿最多一条；开始回收后先完成本竿，再重新下钩。
- 到底自动回收；如果此时仍握住，需要先松开才能开始下一竿。
- 切换标签页、窗口失焦、手柄断连或数据过期时暂停，避免把失焦误当作收钩。
- 轻松／自在／挑战改变鱼速、捕获范围及鱼钩速度，可在两竿之间切换。
- 音效默认关闭，用户主动打开后才创建本地 AudioContext；退出时关闭。

## 场景游玩布局

水域占据主要视窗，左右握持圆钮直接叠放在场景下方，角落显示本次收获、点数及每五条鱼的进度。首次操作后隐藏场景标题，上钩时显示提示并产生少量水泡，收获后出现短暂鱼卡和加分反馈。可主动进入全屏。

图鉴、难度、音效、USB 连接、完整操作说明和开源致谢收进原生对话框。打开面板时暂停并清除握持，关闭时仅在原先未暂停且页面仍处于前台时恢复；期间若窗口失焦或手柄断连则保持暂停。对话框支持 Esc 关闭和原生焦点约束。全局可拖拽动物的默认下方留空增大，避开右侧握持按钮。

鱼群同时最多六条（此前十五条），初始按水平方向错开，离场与捕获后从画面外重新入场。默认“自在”；轻松／自在／挑战的鱼速系数为 1.3／1.8／2.4，相比旧版默认 0.72 更快。个体速度与摆尾节奏略有不同，收钩速度同步提高。六条鱼仍从十种造型中轮换。

十种鱼的图鉴按用户保存在 `puffsqueeze_fishing_collection_v1_<userId>`。读取失败时拒绝覆盖已有数据，本次页面内仍计数。没有云同步或数据库更改，不增加养成 XP。

## 多样鱼类形象

涟漪银鱼、薄荷小河豚、蜜桃扇尾鱼、丁香神仙鱼、金光小锦鲤、月光珍珠鱼，以及新增的杏子小丑鱼、云朵小鳐鱼、微风丝带鱼和奶油方方鱼。

`src/games/fishing/fishArtwork.ts` 为原创矢量轮廓、尾巴、鱼鳍、斑纹及眼睛数据。Canvas 与图鉴 SVG 共用这些路径，避免两处的形象不一致。尾巴以各自的连接点摆动，游向左侧时镜像并保持正立。

保留原六种鱼的存档 ID，因此既有收集数量不丢失。图鉴总数从目录动态读取。捕获范围按各鱼体型的长短、宽窄计算，不使用尾巴或装饰鱼鳍扩大判定。每次进入随机出现六种体型，后续入场按目录权重抽取。

## 现有硬件与新增连接

原来的 `hardware/m5stickcplus_rpc5lt_uploader.ino` 与 HTTP 接口仅上传单次按下事件，无法推断持续握住或松开。游戏不使用历史计数假装实时输入，原上传固件保持原样。

新游戏提供可选 USB Web Serial 接口（115200 波特率），需要支持 Web Serial 的 Chrome／Edge，并在 localhost 或 HTTPS 页面操作。必须由用户点击「连接 USB 手柄」选择端口；不会自动连接设备。

控制器每 50ms 左右发送一行 UTF-8 JSON，并在释放时继续发送零值：

```json
{"type":"puffsqueeze:grip","left":0.65,"right":0.0}
```

- `left` / `right`：0–1 的归一化压力；松开为 0。
- 两侧必须在同一帧，前端一次应用，避免换手产生假的释放。
- 前端按下阈值 0.18、释放阈值 0.10，使用滞回避免噪声抖动。
- 连接后先收到两侧松开的中性帧，再接受握持。
- 首次等待数据宽限 5 秒；开始收到数据后超过 900ms 无有效帧即暂停并清除握持状态。
- 非本协议行、越界值、无效 JSON、启动日志被忽略。
- 暂停恢复后需要先松开；键盘和按钮可独立运行。

配套**示例**固件在 `hardware/fishing_dual_grip_serial/fishing_dual_grip_serial.ino`：

1. 它使用 M5StickC Plus 库、两个模拟压力传感器及各自的分压电路。
2. 示例引脚为左 GPIO36、右 GPIO32；上传前按实际接线修改 `LEFT_PIN` / `RIGHT_PIN`，输入电压须符合板卡 ADC 范围。
3. 启动校准时松开两侧；设备 A 按钮可再次校准。
4. 无 Wi-Fi 连接和凭据，不向后台上报挤压次数。
5. 关闭 Arduino 串口监视器后，再由网页连接相同 USB 端口。

本次只添加示例源码，没有向任何设备烧录，也没有验证实物接线或标定参数。若当前手柄直接模拟键盘方向键，则只需能发送 keydown 与 keyup，即可使用键盘路径，无需串口固件。

## 文件

- `src/screens/FishingScreen.tsx` / `fishing.css`：页面、动物、按钮、图鉴与串口入口。
- `src/games/fishing/engine.ts`：鱼群、Canvas 场景、下钩／收钩状态机、相对运动扫掠碰撞。
- `src/games/fishing/catalog.ts`：鱼类、权重、本地存档。
- `src/games/fishing/fishArtwork.ts`：十种小鱼的共享原创矢量形象。
- `src/services/gripSerial.ts`：串口读取、帧校验、超时与连接释放。
