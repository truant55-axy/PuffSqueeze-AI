## 当前实现

- 本地小智源码：`C:\Users\zhao\Downloads\xiaozhi-esp32-main\xiaozhi-esp32-main`。
- 自定义开发板：`main/boards/puffsqueeze-s3`，GPIO12/13 为左/右游戏键，GPIO8–11 为独立身体声音。
- 游戏列表提供唯一的「连接游戏手柄」入口；钓鱼与飞机订阅全局连接，切换时不关闭串口或无线连接。飞机页面已移除原 USB 和「无线玩偶」行。
- 触摸数据使用既有 Cloudflare WSS relay；语音仍使用小智原有服务。
- 钓鱼：长按 GPIO12/13 任一侧下钩，全部松开收钩；到底保持，松开才收回。
- 飞行：短按 GPIO12 上升一段，短按 GPIO13 下降一段；长按不连发。键盘 ↑/↓、←/→ 和屏幕按钮一致。
- GPIO8 保留原头部撒娇音效；9/10 播放两种脸颊啾啾声；11 播放 “Have you been feeling unhappy today?”。
- 身体触摸只在本地播放，不写入游戏输入；两款游戏均提供 USB 连接，串口与无线连接互斥。
- 铜箔只检测接触/离开，不代表实际压力。

## 首次配对（需要新版固件）

本机若已由开发工具生成 `main/boards/puffsqueeze-s3/grip_pairing.local.h`，在网页点击「导入配对文件」选择该文件即可，不能再生成另一个配对码。文件内容无需粘贴到聊天。

1. 在游戏列表的「连接游戏手柄」选择「无线」，点击「导入配对文件」使用已有的 `grip_pairing.local.h`。
2. 将 `grip_pairing.local.h` 放入小智源码的 `main/boards/puffsqueeze-s3`。
3. 使用已激活的 ESP-IDF 5.4.x 环境，进入小智源码根目录，执行：

```powershell
idf.py -B E:\ESP\build\puffsqueeze-s3 reconfigure
idf.py -B E:\ESP\build\puffsqueeze-s3 build
```

4. 更改固件配对文件时须编译并烧录才能生效；当前设备已烧入配对文件。按用户要求不再创建新备份。
5. 联网、校准完成后，在游戏列表使用相同配对码点击「连接手柄」。先松开铜箔，待「手柄已连接」后进入游戏。

配对文件包含控制权限凭据，不要上传 Git、发送到聊天或贴进截图。文件已在固件项目 .gitignore 中排除。
网页只按账号把配对码保存在当前标签页的 sessionStorage，不上传账号同步服务；换电脑/关闭标签页需要重新输入保存的配对码。
没有配对文件时，固件保持 USB 触摸输出和原有小智聊天，无线发送任务不会启动。

## 断线保护

- 新连接、设备重连、页面失焦和信号过期后，先暂停、清空输入，再等待实际松开。
- 网页拒绝重复序号、旧时间戳和延迟超过约 1 秒的帧，约 1.1 秒没有有效心跳则暂停。
- 设备在状态变化时发送，松开和握住都持续发送心跳；最多 25 帧/秒。校准/采样失效时关闭控制连接，不伪造持续握住。
- 全局 USB 与无线连接互斥；键盘与触屏仍保留。每个游戏只接收当前订阅的输入，切换方向先处理松开，避免误触双键暂停。
- 同一个配对码仅允许一个网页和一个玩偶；网页被另一页面替换后不会自动争抢连接。
- 服务端是持有码即可连接的原型配对，尚不是后端账号所有权绑定；不会自动同步小智语音聊天记录。
